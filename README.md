# Cycle 11 — frozen signal bridge
Python standard library only. Run `python -m unittest -v`.
Use `bridge.run(bars, signals, threshold=..., roundtrip_bps=10, dividends=..., splits=...)` with ledger.Bar and bridge.Signal objects. Signal date is after close; train_end, calibration_end, policy_end are latest label availability dates for each stage, not merely feature dates. Metadata is not proof of provenance. Supply a complete exchange session calendar and verified raw prices/actions. Threshold must be selected before evaluation. Each accepted signal enters next open, expires five open-to-open intervals later; overlapping sleeves are daily rebalanced using previous close equity and price, not fixed-share lots. Opening cash/gross clipping is a simulated execution constraint, not a guaranteed broker fill. Costs charged on net traded notional, half round-trip bps per side. Signals without complete horizon are excluded; use identical evaluation windows. Dividend pay dates must be included in bars for inherited ledger. No shorting in bridge, no financing, settlement, market impact, independent reconciliation or volatility targeting yet. Do not treat synthetic tests as market evidence.
